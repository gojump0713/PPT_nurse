# 영남이공대·영남대병원 발표 — HTML 발표자료 작업지시서 + 화면설계서

**산출물 목표**: 이 문서를 AI 코딩 도구에 그대로 전달하면 HTML/CSS/JS 발표자료를 구현할 수 있는 설계 문서
**기준 텍스트**: 「24페이지 텍스트 확정본」 (제목·거버닝 메시지 확정 완료본)

---

# PART A. 작업지시서 (공통 사양)

## 1. 기본 사양

- 형식: 브라우저 전체화면 Full Screen Presentation (PPT 아님, 웹사이트 아님)
- 화면비 16:9, 기준 해상도 1920×1080, `transform: scale()` 기반 반응 축소
- 총 24개 SCREEN, 페이지 단위 전환, 세로 스크롤 금지
- 조작: → / Space / 화면 클릭 = 다음 단계 또는 다음 페이지, ← = 이전, ESC = 전체 목차 오버레이, 숫자키+Enter = 페이지 점프
- 우하단 고정: 현재 페이지 / 24 (예: `07 / 24`), PART 표시 (CBT · VDI · TILON)
- 발표 중 커서 자동 숨김(3초), 불필요 UI 없음

## 2. 페이지 전환 규칙

- 기본 전환: 0.6초 Fade + 20px Slide-up
- PART 전환(14→15, 21→22): 1.2초 전용 전환 연출 (각 SCREEN 설계 참조)
- 페이지 진입 시 요소 등장 순서: 제목(0s) → 거버닝 메시지(0.4s) → 본문 요소(0.8s~ 시간차 0.15s 간격)

## 3. 클릭 정책 (전 화면 공통)

- 일반 페이지 0~1회, 비교·전환 페이지 최대 2회
- 클릭이 남아 있는 화면은 우하단에 작은 ▸ 인디케이터 표시, 클릭 소진 시 인디케이터가 「다음 페이지 →」로 변경
- 클릭 없이 5초 경과 시 인디케이터 미세 펄스 (발표자 리마인드)

## 4. 텍스트 위계 (공통 타이포 스케일)

| 요소 | 크기 | 웨이트 |
|---|---|---|
| Big Number | 240~360px | 800 |
| 거버닝 메시지 | 44~56px | 700 |
| 제목(페이지 상단) | 28px | 600 |
| 핵심 키워드 카드 | 24~32px | 600 |
| 설명문 | 20~22px | 400 |
| 출처·각주 | 14px | 400, 투명도 60% |

원칙: 거버닝 메시지가 화면에서 가장 큰 "문장". 제목은 상단 좌측의 안내 역할로 축소.

# PART B. 페이지별 화면설계서

## SCREEN 01

### 제목
2028년 간호사 국시 CBT 전환

### 거버닝 메시지
**시험이 바뀌면, 준비하는 환경도 바뀌어야 합니다.**

### 화면 목적
발표 전체의 출발점. 제품이 아니라 "확정된 외부 변화"를 던지고, 청중 스스로 준비 상태를 자문하게 만든다.

### 화면에 실제 표시할 텍스트
- Big Number: `2028`
- 서브: `제68회 간호사 국가시험 · CBT 전환`
- 거버닝 메시지: `시험이 바뀌면, 준비하는 환경도 바뀌어야 합니다.`
- 핵심 질문(클릭 후): `우리 학생들은 국가시험 전에 CBT를 몇 번 경험하게 됩니까?`
- 각주: `한국보건의료인국가시험원 발표(2025.11.17) · 간호법 시행규칙 부칙`

### 주요 발표 멘트
1. "오늘은 제품 이야기가 아니라, 확정된 변화 하나에서 시작하겠습니다."
2. "2028년 제68회 간호사 국가시험이 컴퓨터 기반 시험으로 전환됩니다."
3. "그래서 오늘 발표는 이 질문 하나로 시작합니다 — 우리 학생들은 시험 전에 CBT를 몇 번 경험하게 됩니까?"

### 화면 구성
- 중앙: `2028` Big Number (화면 높이의 40%)
- 중앙 하단: 서브 텍스트 → 거버닝 메시지 순차 등장
- 클릭 후: 2028이 좌상단으로 축소 이동, 중앙에 핵심 질문 대체 등장
- 하단: 각주 (투명도 60%)

### 데이터 활용
`2028` 단일 숫자를 화면의 주인공으로. 카운트업 없음(확정 사실은 정적으로 무겁게).

### 이미지 활용
없음. 타이포그래피 온리 (오프닝의 무게감 유지).

### 영상 활용
없음.

### 인터랙션·애니메이션
① 로드: 어두운 배경에서 `2028` 페이드인(1.2s) ② 자동(1.5s 후): 서브 텍스트 등장 ③ 자동(1s 후): 거버닝 메시지 등장 ④ 클릭 1회: 숫자 축소 + 핵심 질문 등장

### 클릭 횟수
1회

### 인터랙션을 사용하는 이유
"연도 → 사실 → 질문"의 3박자 리듬으로 청중의 주의를 단계적으로 조이기 위함. 질문은 발표자의 타이밍에 맞춰야 하므로 마지막만 클릭.

### 다음 화면 연결 멘트
"그런데 이 변화, 종이가 화면으로 바뀌는 정도라고 생각하시면 곤란합니다. 무엇이 바뀌는지 숫자로 보겠습니다."

## SCREEN 02

### 제목
8과목 295문항 → 2과목 200문항

### 거버닝 메시지
**시험지가 아니라, 시험의 구조와 응시 행동이 바뀝니다.**

### 화면 목적
개편의 실체를 숫자로 각인. "구조 재편 + 행동 변화"라는 이중 변화를 이해시킨다.

### 화면에 실제 표시할 텍스트
- 좌측 헤더: `현행 PBT` / 우측 헤더: `2028 CBT`
- 대비 숫자 3쌍: `8과목 → 2과목` `295문항 → 200문항` `3교시 → 2교시 (각 95분)`
- 우측 하단 보조: `간호학총론 7분야 47영역` `보건의약관계법규 13개 법 19영역 · 간호법 신설`
- 하단 행동 비교 띠: `문제지·마킹·정해진 순서` → `화면 판독·문항 이동·답안 수정·시간 관리`

### 주요 발표 멘트
1. "8과목 295문항 3교시가, 2과목 200문항 2교시로 재편됩니다."
2. "간호학총론 하나로 7분야 47영역이 통합되고, 법규 과목에는 간호법이 첫 번째 법으로 들어옵니다."
3. "즉 종이가 화면이 되는 게 아니라, 시험을 치르는 행동 자체가 바뀝니다."

### 화면 구성
- 상단 좌: 제목 / 상단 중앙: 거버닝 메시지
- 중앙: 좌우 2컬럼 대비. 좌측(회색 톤) PBT, 우측(포인트 컬러) CBT
- 중앙 3행: 과목·문항·교시 숫자 대비 (숫자 120px)
- 하단: 응시 행동 Before→After 가로 띠

### 데이터 활용
Before/After + Count 전환: 클릭 시 좌측 숫자가 우측 숫자로 카운트다운 모핑 (295→200, 8→2, 3→2). `95분`은 우측에 신규 등장.

### 이미지 활용
없음 (숫자가 주인공).

### 영상 활용
없음.

### 인터랙션·애니메이션
① 로드: PBT 컬럼만 표시 ② 클릭 1회: 숫자 모핑 + CBT 컬럼 점등 + 행동 띠 슬라이드인

### 클릭 횟수
1회

### 인터랙션을 사용하는 이유
"현재 상태를 먼저 보여주고 변화를 발표자 타이밍에 터뜨리는" 구조가 개편의 낙차를 가장 크게 전달.

### 다음 화면 연결 멘트
"이 낯선 시험 행동을, 학생이 국가시험 당일에 처음 해본다면 어떻게 될까요?"

## SCREEN 03

### 제목
시험 당일 첫 CBT 경험 차단

### 거버닝 메시지
**CBT는 시험 당일 처음 경험해서는 안 됩니다.**

### 화면 목적
발표의 감정적 핵심 ①. 학생이 사전에 익숙해질 9가지를 실제 CBT 화면 위에서 보여준다.

### 화면에 실제 표시할 텍스트
- 거버닝 메시지 (화면 상단, 최대 크기)
- CBT 화면 위 핫스팟 라벨 9개: `① PC 기반 문제풀이` `② 장문 문항 화면 판독` `③ 문항 이동` `④ 문항 체크` `⑤ 미응답 확인` `⑥ 답안 수정` `⑦ 제한시간 관리` `⑧ 계산기·메모 도구` `⑨ 장시간 화면 집중`
- 하단 질문: `내용은 아는데 환경이 낯설어 실력을 못 냈다면, 그것도 학생의 실력입니까?`

### 주요 발표 멘트
1. "국가시험 당일은 학생 인생에서 가장 긴장되는 95분입니다."
2. "그 순간에 화면에 보이는 이 9가지를 처음 만나서는 안 됩니다."
3. "내용은 아는데 환경이 낯설어 실력을 못 냈다면 — 그것도 학생의 실력이라고 할 수 있을까요?"

### 화면 구성
- 상단: 거버닝 메시지
- 중앙: 실제 틸론 CBT 응시 화면 스크린샷 (제주대 매뉴얼 기반, 70% 폭)
- 스크린샷 주변: 9개 핫스팟 라벨이 해당 UI 요소를 가리키며 순차 점등
- 하단: 핵심 질문 (마지막 자동 등장)

### 데이터 활용
`9가지` 카운터가 라벨 점등에 맞춰 1→9 증가 (우측 상단 소형).

### 이미지 활용
- 필요 이미지: 틸론 CBT 학생 응시 화면 캡처 1장 (문항·타이머·이동 버튼·체크 기능이 모두 보이는 화면)
- 위치: 중앙 / 목적: "추상적 걱정"을 "구체적 화면"으로 치환
- 출처: CBT 학생매뉴얼 PDF 내 화면 캡처 활용

### 영상 활용
없음 (S14에서 영상 사용 예정이므로 여기선 정지 화면으로 긴장 유지).

### 인터랙션·애니메이션
① 로드: 거버닝 메시지 + CBT 화면 등장 ② 자동: 9개 핫스팟이 0.5s 간격 순차 점등 ③ 자동: 하단 질문 페이드인. Hover 시 각 라벨 확대 툴팁(발표자 재량).

### 클릭 횟수
0회

### 인터랙션을 사용하는 이유
9개 항목을 한꺼번에 리스트로 뿌리면 읽지 않는다. 실제 화면 위 순차 점등이 "낯섦의 실체"를 가장 직관적으로 전달.

### 다음 화면 연결 멘트
"교수님들은 이 문제의 답을 이미 알고 계십니다. 실습 교육에서 늘 하고 계신 방식입니다."

## SCREEN 04

### 제목
시뮬레이션 실습 원리의 시험 적용

### 거버닝 메시지
**임상실습 전에 시뮬레이션을 하듯, 국가시험 전에 CBT를 반복해야 합니다.**

### 화면 목적
청중(간호·보건 교수)의 기존 신념에 CBT를 접붙이는 설득의 지렛대. 새 주장 없이 공감만 얻는다.

### 화면에 실제 표시할 텍스트
- 상단 트랙 라벨: `임상 교육` — `교육 → 실습 → 시뮬레이션 → 반복 → 임상`
- 하단 트랙 라벨: `시험 준비` — `학습 → CBT 체험 → 과목시험 → 모의시험 → 국가시험`
- 중앙 연결 문구: `실전에서 처음 경험하지 않도록, 사전에 반복한다`

### 주요 발표 멘트
1. "우리는 학생을 실제 환자 앞에 바로 세우지 않습니다. 시뮬레이션과 반복 실습을 거치게 합니다."
2. "이유는 하나죠 — 실전에서 처음 경험하지 않게 하기 위해서입니다."
3. "시험도 정확히 같은 원리입니다. CBT 반복은 시험의 시뮬레이션입니다."

### 화면 구성
- 중앙: 상하 평행 2트랙 다이어그램 (각 5단계 노드)
- 두 트랙 사이: 공통 원리 문구
- 상단: 거버닝 메시지

### 데이터 활용
없음 (유추 논리 페이지 — 숫자 배제로 서사에 집중).

### 이미지 활용
- 각 트랙 마지막 노드에 아이콘: 임상(청진기) / 국가시험(모니터)
- 선택: 시뮬레이션 실습실 사진 1장을 상단 트랙 배경으로 흐리게 (검색 키워드: `간호 시뮬레이션 실습실 마네킹`)

### 영상 활용
없음.

### 인터랙션·애니메이션
① 로드: 두 트랙의 첫 노드만 표시 ② 자동: 두 트랙이 좌→우로 동시 진행 (노드 0.6s 간격 점등) ③ 자동: 마지막 노드 도달 시 중앙 공통 원리 문구 등장

### 클릭 횟수
0회

### 인터랙션을 사용하는 이유
두 경로의 "동시 진행"이 유추의 핵심. 나란히 움직여야 같은 원리임이 말 없이 전달된다.

### 다음 화면 연결 멘트
"그럼 그 반복을 언제부터 시작해야 할까요? 4학년 2학기는 이미 늦습니다."

## SCREEN 05

### 제목
재학 4년 전체의 CBT 상시화

### 거버닝 메시지
**2028년에 시스템을 구축하는 것이 아니라, 2028년 응시생을 지금부터 준비시키는 것입니다.**

### 화면 목적
"언제부터"에 대한 답. 4년 설계와 2026년 역산이라는 시간 압박을 심는다.

### 화면에 실제 표시할 텍스트
- 타임라인 노드 4개: `1학년 — CBT 체험·기초과목 평가` `2학년 — 중간·기말 CBT 전환` `3학년 — 통합형·반복 모의 CBT` `4학년 — 2교시 95분 실전 모의`
- 종착점: `국가시험 = 이미 익숙한 환경`
- 우측 역산 배지: `2028 응시 ← 준비 시작 2026`
